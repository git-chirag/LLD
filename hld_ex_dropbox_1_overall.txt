11. Conflict Resolution

Scenario:

Laptop Offline
Phone Offline

Both modify:

resume.pdf

Both reconnect.

Problem:

Two valid updates

Options:

Conflict Copy

Dropbox approach.

resume.pdf

resume(conflicted copy).pdf
Last Write Wins

Simple.

Not ideal.

Operational Transform / CRDT

Google Docs style.

Too complex for Dropbox.

12. Deduplication

Goal:

Store identical content only once.

Example:

Ubuntu.iso

uploaded by:

1000 users

Store:

1 copy

Metadata:

User A -> Hash XYZ

User B -> Hash XYZ

Benefits:

Huge storage savings

Copy-On-Write
