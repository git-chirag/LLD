Build a complete Python Parking Lot System using object-oriented design and design patterns. The goal is educational and interview preparation, not just a working solution.

The implementation should be structured like a small production project and demonstrate clean architecture, SOLID principles, encapsulation, composition over inheritance, extensibility, and maintainability.

Use Python 3.11+.

---

The project should be usable as a reference implementation for future LLD problems such as:

* Library Management System

## DESIGN REQUIREMENTS

Use composition over inheritance whenever possible.

Avoid enum explosion such as:

EV_CAR_SPOT
HANDICAP_CAR_SPOT
EV_HANDICAP_CAR_SPOT

Instead use:

SpotFeature Enum
and composition.

Use strong encapsulation.

Public APIs should be exposed through methods.

Avoid directly modifying internal state.

Example:

GOOD:
spot.park(vehicle)

BAD:
spot.vehicle = vehicle
spot.is_occupied = True

    vehicle

park(vehicle)

unpark()

is_occupied
Thread Safety
def park(self, vehicle):

    with self._lock:

        if not self.can_fit(vehicle):
            raise Exception()

        self.vehicle = vehicle

This prevents:

Two threads reserving same spot
