Traffic distribution

Better resource utilization

5. Proxy vs Passthrough
Proxy Mode

ALB usually works like this.

Client
   |
TCP Connection #1
   |
ALB
   |
TCP Connection #2
   |
Backend

Two separate TCP connections.

ALB becomes a TCP endpoint.

This is called:

TCP Termination
What does TCP termination mean?

It does NOT mean:

Close connection

It means:

Connection ends at ALB.

ALB establishes a new connection to backend.

Passthrough Mode

Usually used by L4 load balancers.

Client
   |
NLB
   |
Backend

LB forwards packets without understanding application data.

No HTTP parsing.

No URL inspection.

ServerB

Interview Questions You Should Be Able To Answer
Why use a load balancer?

Traffic distribution, availability, scalability.

Difference between ALB and NLB?

L7 vs L4, HTTP-aware vs TCP/UDP-aware.

What is TLS termination?

Load balancer decrypts TLS traffic and becomes the TLS endpoint.

Why can't NLB route /orders differently from /users?

It cannot inspect HTTP payload.

What are sticky sessions?

Same user consistently routed to same backend.

What are health checks?

Periodic validation of backend health.

What is connection draining?

Allow active requests to finish before removing a server.

How do you avoid load balancer SPOF?

Multiple load balancers + DNS failover.

When would you choose NLB over ALB?

Kafka, Redis, databases, custom TCP/UDP protocols, ultra-low latency systems.

Amazon Interview Answer

If asked:

What is the difference between a Reverse Proxy and an API Gateway?

Answer:

A reverse proxy primarily sits in front of backend servers and provides routing, TLS termination, caching, compression, and security features. An API Gateway is a specialized reverse proxy designed for microservices that additionally provides authentication, authorization, rate limiting, request aggregation, API versioning, and API lifecycle management.

For SDE2 interviews, that's exactly the level of understanding they expect.
